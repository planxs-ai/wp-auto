# 애드센스 심사 준비 — 2026-09-12

이 변경은 자동 생성 글의 공개 전 검토를 보장하는 코드 변경입니다. 승인 획득, 실제 WordPress 반영, 기존 글의 사실 확인까지 완료한 상태는 아닙니다.

## 확인한 문제와 변경

- 일반/AdSense/Golden/니치 프롬프트의 가상 체험·경력 지시를 제거하고 모든 모드에 근거 규칙을 추가했습니다. 프롬프트 자체는 사실 확인을 보장하지 않습니다.
- `EDITORIAL_REVIEW_REQUIRED` 기본값은 true입니다. 기존 예약 주기는 유지되지만 해당 워크플로는 초안만 저장합니다. Stage 1 또는 `--adsense-mode`는 이 값을 false로 설정해도 초안입니다. 다른 단계에서도 품질 미달·신뢰도 경고는 초안입니다.
- 초안은 공개 발행 집계, SNS 공유, IndexNow/사이트맵 핑 대상에서 제외됩니다. 관리자 최근 글 목록에는 ‘검토 대기’로 표시합니다. 소비자 공개 글 목록에는 포함하지 않습니다.
- WordPress에서 실제 반환한 상태를 확인합니다. 잘못된 robots 메타 쓰기를 제거했습니다. 기존 SEO 플러그인의 설정을 사용합니다.
- 사용 키워드 자동 초기화/재활용을 제거하고 유사도 0.8 이상의 중복 후보는 생성 전에 건너뜁니다. 이는 내부 중복 방지 기준이며 Google 기준이 아닙니다.
- `setup_pages.py`와 `main.py --setup-pages`는 소개/문의/개인정보/편집원칙의 **누락된 페이지만 초안 생성**합니다. 기존 페이지는 보존하며 조회 실패 시 새 페이지를 만들지 않습니다. 이용약관·면책문구를 검증 없이 새로 공개하지 않습니다.
- 운영자/소개/실제 연락처가 없으면 페이지 생성을 중단합니다. 개인정보 초안의 `[확인 필요]`는 운영 현황으로 채운 뒤 공개해야 합니다.
- 20편·30편, 85점·90점, 정해진 재신청 일수만으로 승인 가능하다는 대시보드 안내를 수정했습니다.

## 실제 공개 페이지 확인

웹 조회로 [planx-ai.com](https://planx-ai.com/)과 [bomissu.com](https://bomissu.com/)의 공개 홈을 확인했습니다. 두 사이트 모두 운영 중이며 이 저장소에는 두 사이트용 예약 작업이 있습니다.

[planx-ai.com의 배당 포트폴리오 글](https://planx-ai.com/dividend-stock-2026-5/)에는 개인 운용 경험과 변동폭 비교 성과를 주장하는 부분이 있습니다. 주장에 대응하는 실제 기록을 이번 검토에서는 확인하지 못했습니다. 기록이 없다면 해당 경험·성과 주장을 삭제하고, 검증된 원문에 근거한 설명으로 수정해야 합니다. 허위라고 확정한 것은 아닙니다.

[현재 개인정보처리방침](https://planx-ai.com/privacy-policy/)의 공개 본문에는 Google 광고 설정을 통한 맞춤 광고 해제 안내가 보이지 않았습니다. 실제 활성화된 광고·분석 서비스와 보유 기간을 확인하고 해당 안내를 보완해야 합니다. 기존 페이지를 자동 덮어쓰지는 않았습니다.

## 적용 및 심사 전 순서

1. 이 PR의 테스트 확인 후 병합하면 기존 AutoBlog 예약 작업의 결과가 공개 글에서 초안으로 바뀝니다. 생성 API 사용 비용은 계속 발생합니다. 쿠팡 딜 엔진 PR #2는 별도이며 이 PR에 포함되지 않습니다.
2. WordPress 관리자에서 최신 초안 1편을 열어 제목/본문/출처/날짜/이미지 권리/실제 체험 근거를 확인하고 공개합니다. 공개 후 모바일과 비로그인 환경에서 메뉴·본문·링크·SEO 설정을 확인합니다. 초안을 수동 공개해도 기존 대시보드 로그가 자동으로 published로 바뀌는 기능은 이번 범위에 없습니다.
3. 기존 공개 글의 중복·체험·성과 주장부터 수정합니다. 아래 읽기 전용 도구는 검토 후보 목록만 만들며 자동 삭제/수정하지 않습니다.

```bash
python scripts/audit_adsense.py --url https://planx-ai.com --max-pages 5
python scripts/audit_adsense.py --url https://bomissu.com --max-pages 5
```

기본 최신 20편, 최대 100편까지 조회합니다. `sample_complete: false`면 전체 글 점검이 아닙니다. REST API 차단이나 조회 오류는 `errors`에 표시하고 종료코드 1을 반환합니다. 정규식과 외부 링크 유무는 심사 합격 판정이나 사실 검증이 아닙니다. robots.txt, 전체 링크 상태, 로그인 요구, 모바일 레이아웃, 모든 Google 크롤러 접근 여부는 별도 직접 점검 대상입니다.

이 작업 환경에서 위 Python 도구의 실사이트 요청은 네트워크 접근에 실패했습니다. 이를 사이트 장애로 판정하지 않았습니다. 공개 페이지 내용은 별도 웹 조회로 확인했습니다. API 자격증명, WordPress 쓰기, AI 생성 호출, 쿠팡 호출, 워크플로 수동 실행은 수행하지 않았습니다.
